# Teacher-v9.8.12 saved affordance-map viewer

Read-only Viser viewer for the two train scenes saved by the validated
Teacher-v9.8.12 run. It displays Input RGB, all-sittable or per-object GT,
the radius-0.006 starting state, any of the six update states, update-minus-start
and absolute error against GT.

No model, diffusion, optimizer, checkpoint, development scene or paper-test
payload is loaded. Continuous XY surfaces are display-only interpolation over
the original 8192 point values.
