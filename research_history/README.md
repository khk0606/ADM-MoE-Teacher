# Teacher research history

This directory keeps immutable Teacher-LoRA experiment deliveries out of the
repository root. They document the v9-v10.3.1 research progression and are not
imported directly by the current runtime.

- `teacher_lora_packages/`: versioned delivery packages, validators, and runbooks
- `../prepare/`: combined runnable Python implementation
- `../scripts/teacher_v102/`: release verification and public-result utilities
- `../docs/TEACHER_EXPERIMENT_HISTORY.md`: milestone outcomes and reproduction order

Run commands from the repository root so each package can find the shared
`prepare/` and `data/` directories.
