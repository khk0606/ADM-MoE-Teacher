# Teacher-v9.6 object-balanced consensus gate

Teacher-v9.5 found a valid local common direction but its smallest radius still
regressed Bed and normal Chair at the disclosed `t=475` watch panel while High
Chair remained flat. Larger radii harmed High Chair.

This fail-closed gate uses every one of the eight already disclosed timestep /
noise panels as design evidence. It constructs four directions: task-common,
equal-object, Chair-pair-priority, and High-Chair-priority. Priority directions
are blended only inside the half-space where all 48 design-task directional
derivatives remain positive.

Four radii per direction are evaluated on four new audit panels. A single
object/prompt/panel exact-top-k regression rejects a candidate. No checkpoint
is written, only `room_0101` arrays are loaded, and development/paper-test data
remain unread.
